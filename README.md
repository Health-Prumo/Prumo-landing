# Prumo · landing page

Página de apresentação do Prumo, coach de bem-estar com IA. Arquivo único (`index.html`), sem build: HTML, CSS e JavaScript puros, com as fontes Cormorant Garamond e Inter do Google Fonts.

## Como ver

Abra o `index.html` no navegador ou publique a pasta em qualquer hospedagem estática (GitHub Pages, Vercel, S3 + CloudFront).

## Lista de acesso antecipado

O formulário só envia depois de configurar um endpoint. No fim do `index.html`, preencha `const ENDPOINT = ''` com a URL de um serviço de formulários (Formspree, por exemplo). Sem isso, o formulário avisa que a lista abre em breve e não guarda nada.

## Identidade visual

Segue o guia da marca no repositório [`prumo`](https://github.com/Health-Prumo/prumo/blob/main/docs/04-identidade-visual.md): base branca, verde-esmeralda como contraste, menta como destaque, sem dourado.
